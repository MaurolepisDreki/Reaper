# Reaper

Reaper is a **Repository Manager** for building and maintaining modularized code
repositories, much as pacman builds operating systems or Rails manages
boilerplate for Rails apps.

It is more of a local environment manager than a code maintainer. Its purpose is
to help manage and cascade project boilerplate across multiple projects that
live as separate codebases instead of conventional packages.

## Requirements

- Bash
- Standard GNU/Linux command-line utilities
